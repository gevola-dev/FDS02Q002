## Plan
The EXAM consists of
- 70% MACHINE LEARNING PROJECT
- 30% WRITTEN EXAMINATION

### MACHINE LEARNING PROJECT
- KAGGLE DATASET (AMONG THE ALLOWED ONES, MORE THAN 50)
- PROJECT TEAM (MINIMUM 2 MEMBERS, MAXIMUM 5 MEMBERS)
- A KNIME WORKFLOW
- TECHNICAL REPORT (≤ 8 PAGES, TEMPLATE AND SAMPLES PROVIDED)
- CLEARLY STATED JUDGEMENT CRITERIA (A POSSIBLY PRECISE DEFINITION OF)
- Submit your PDF project together with the associated KNIME workflow.
- Your project is assumed to be a PFD file smaller than 10MB. Furthermore, the first page of the PDF must list name and surname of all the team's members.
- Export the KNIME workflow by setting "Exclude data from export"
- Compress the exported KNIME workflow and the PDF of your project using the "rar" utility.
- Name the "rar" file with your team name, i.e. if you belong to team 11, then your "rar" file should be TEAM 11.rar.
- Be sure your "TEAM 05.rar" file is smaller than 10MB
- Upload the "TEAM 05.rar" file to the platform
- Just one member per team must submit
- In case you already uploaded your project and want to upload a new release, write an email to me mentioning the issue and mentionining your TEAM name.
- If you have any issues or experiment any problems, do not hesitate to contact me.

#### The following criteria are used to evaluate the ML Project.
Technical merit: notably rigour, accuracy and correctness.
Clarity of expression and communication of ideas; including readability and discussion of concepts.
Appropriate referencing and the context of the present work.
Overall balance and structure of report.
Repetition; have significant parts of the manuscript already been published by other authors? 
Diagrams, tables, captions; are they clear and essential

###  WRITTEN EXAMINATION ON (*) LECTURES
- INDIVIDUAL WRITTEN EXAM
- 1 QUESTION WITH OPEN ANSWER 5 PTS
- 6 QUIZ STYLE QUESTIONS (MULTIPLE CHOICE) 1 PT EACH
- 40 MINUTES FOR ACCOMPLISHING THE ASSIGNMENT

## Module 1
Obbligatori 5 di 5

1.1 - Data Types (*)
In this lecture you will learn how to design and develop a workflow to load different formats of data set. You will also learn how to set different types of attributes, namely categorical and nominal. (1:05 hours)

1.2 - Exploration (*)
In this lecture you will learn how to develop a workflow to summarize an attribute depending on its type and how to discover anomalous records associated with an attribute. (1:08 hours)

1.3 - Missing Replacement (*)
In this lecture you will learn how to cope with the missing data problem. In particular, you will learn how to develop a workflow for missing data replacement of different types of attributes. (1:04 hours)

1.4 - Preprocessing Part I (*)
This lecture will teach you how to develop a workflow to reduce the dimensionality of a data set in terms of both attributes and records. (1:16 hours)

1.5 - Preprocessing Part II (*)
In this lecture you will learn how to develop a workflow for reducing the dimensionality of the data set with specific reference to binarization, discretization and transformation of an attribute. (1:05 hours)

## Module 2
Obbligatori 1 di 7

2.1 - Introduction (*)
In this lecture you will learn the difference between using the same set of data or different partitions of the available data to develop and use a classification model. (1:24 hours)

2.2 - Classification Techniques - Part I
In this lecture you will learn how to develop the following classification models; decision tree and logistic regression for solving the binary classification problem. (0:39 hours)

2.3 - Classification Techniques - Part II
In this lecture you will learn how to develop a Support Vector Machine classifier to solve the problem of binary classification. (0:29 hours)

2.4 - Classification Techniques - Part III
In this lecture you will learn how to develop a Multi Layer Perceptron classifier to solve the problem of binary classification. (0:19 hours)

2.5 - Classification Techniques - Part IV
In this lecture you will learn how to develop the Naïve Bayes classification model to solve a binary classification problem. (0:32 hours)

2.6 - Classification Techniques - Part V
In this lecture you will learn how to develop Bayesian network classifiers to solve a binary classification problem. (0:15 hours)

2.7 - Classification Techniques - Practice
In this lecture you are asked to put it all together, lectures from 2.2 to 2.6 and to develop and compare different classification models to solve a binary classification problem. (1:30 hours)

## Module 3
Obbligatori 3 di 4

3.1 - Performance Evaluation - Part I (*)
In this lecture you will learn about training error, generalization error, and risk to overfit or underfit a data set. (0:33 hours)

3.2 - Performance Evaluation - Part II (*)
In this lecture you will learn how to develop a workflow for evaluating different performance measures of a classification model. (1:35 hours)

3.3 - Comparing Classifiers (*)
In this lecture you will learn how to develop a workflow for comparing the performance achieved by different classification models and thus how to select the “optimal classification model”. (2:22 hours)

3.4 - Linear RegressionBook
In this lecture you will learn how to develop a workflow implementing linear regression. You will learn how to develop and validate a linear regression model and how this can be done by using the KNIME platform and it's interface to the R language. (2:13 hours)

## Module 4
Obbligatori 6 di 6 

4.1 - Class Imbalance Problem (*)
In this lecture you will learn how to develop a workflow to solve a binary classification problem when one of the two classes is “rare”. (1:15 hours)

4.2 - Counting the Cost - part I (*)
In this lecture you will learn how to develop a workflow for solving a binary classification problem when a cost matrix is available and the expected cost has to be minimized. (1:12 hours)

4.3 - Counting the Cost - part II (*)
This lecture will teach you how to develop a workflow for comparing classifiers when a cost matrix is not available and you are asked to ponder different scenarios. (0:26 hours)

4.4 - Counting the Cost - part III (*)
In this lecture you will learn how to develop a workflow for comparing the performance achieved by different classification models using receiver operating characteristic curves and lift charts. (1:06 hours)

4.5 - Feature Selection (*)
This lecture will teach you how to develop a workflow for identifying and removing useless attributes for solving a binary classification problem. (1:31 hours)

4.6 - Non Binary Classification (*)
This lecture describes how to solve non binary classification problems with specific reference to multi-class and multi-label classification. (1:00 hours)

## Module 5
Obbligatori 2 di 2

5.1 - Introduction to Clustering (*)
This lecture introduces Cluster Analysis, and its’ different purposes. You will learn about different types of clustering, including; exclusive/overlapping/fuzzy, partitional/hierarchical and complete/partial. Finally, the lecture introduces different notions of cluster and describes the main components of Cluster Analysis. (1:33 hours)

5.2 - Proximity (*)
You will learn about proximity, and how to compute similarity/dissimilarity for nominal, ordinal and numeric attributes. This lecture introduces the class of Minkowski measures, the simple matching coefficient, the Jaccard coefficient, the cosine similarity, correlation, and the Mahalanobis distance. Furthermore, the lecture gives the definitions of symmetric and asymmetric attribute. You will learn to develop a workflow to compute proximity between records consisting of different types of attributes. (2:05 hours)

## Module 6
Obbligatori 0 di 5

6.1 - Prototype-Based
This lecture teaches you about prototype-based clustering algorithms with specific reference to; K-means, Fuzzy C-means, mixture models and Self Organizing Maps. (1:19 hours)

6.2 - Hierarchical Agglomerative
This lecture teaches you about agglomerative and divisive hierarchical clustering. In particular, you will learn about single linkage, complete linkage, average linkage and Ward’s method. Furthermore, the lecture introduces the dendrogram tool. (0:22 hours)

6.3 - Density-Based
This lecture teaches you about density-based clustering algorithms with specific reference to DBSCAN. Furthermore, the lecture introduces the concepts of density, and neighborhood as well as the concepts of core, border and noise point. (0:30 hours)

6.4 - Graph-Based
This lecture teaches you about the concepts of sparsification and proximity graph. Furthermore, the lecture introduces graph-based clustering with specific reference to the minimum spanning tree, Opossum and Chameleon algorithms. (1:15 hours)

6.5 - Clustering Algorithms - Practice
In this practice session you are asked to develop a workflow to implement the following clustering algorithms; K-means, Fuzzy C-means, mixture models, Self Organizing Maps, hierarchical agglomerative, DBSCAN and graph-based. You are also asked to inspect and criticize the obtained results by applying the above clustering algorithms. (1:00 hours)

## Module 7
Obbligatori 4 di 4

7.1 - External Measures (*)
This lecture teaches you about the main issues of cluster validation and introduces which are the main types of evaluation measure. In particular, external or supervised measures are presented. (1:00 hours)

7.2 - Internal Measures (*)
This lecture teaches you about internal or unsupervised indices for clustering validation. In particular, the lecture introduces the concepts of cohesion, separation, silhouette coefficient and cophenetic correlation coefficient. (1:07 hours)

7.3 - Validity Paradigm (*)
This lecture teaches you about the validity paradigm. (0:27 hours)

7.4 - The Fundamental Problem (*)
In this lecture you will learn about different relative indices. Furthermore, the lecture teaches how to use relative indices to solve the fundamental problem of cluster validity. (0:47 hours)

## Module 8
Obbligatori 2 di 5

8.1 - Introduction (*)
This lecture teaches you how to develop a workflow to find frequent itemsets, to extract association rules, and to compute their revenue. Furthermore, you will also learn how to summarize the extracted association rules. (0:46 hours)

8.2 - Rules Extraction
This lecture teaches you how to develop a workflow to extract association rules from a transactions dataset by using the Apriori principle. Furthermore, the lecture teaches you about candidate itemset, apriori principle, support-based pruning and the Apriori algorithm. (0:30 hours)

8.3 - Maximal/Closed Frequent Itemsets
This lecture teaches you how to find frequent, maximal and closed itemsets using both the Apriori and the FPgrowth algorithms. This lecture also teaches you about redundant association rules. (1:16 hours)

8.4 - Rules Evaluation (*)
You will learn to develop a workflow for reading the content of a market basket, calculating its total price and finding a match with a given antecedent. You will also learn about interesting and uninteresting association rule, objective interestingness measures, symmetric and asymmetric objective measures, and how to select the appropriate objective measure for rule evaluation. (1:20 hours)

8.5 - Simpson's Paradox
This lecture teaches you about the Simpson’s paradox, a paradox you need to understand to avoid potential errors in mining transactions data. However, the Simpson’s paradox is extremely important for all Machine Learning tasks. (0:33 hours)
